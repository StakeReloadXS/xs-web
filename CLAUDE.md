# CLAUDE.md

Guidance for Claude Code sessions in this repo. `AGENTS.md` holds the rules every agent follows. `CONTRIBUTING.md` holds the workflow.

## What this is

Static StakeReloadXS storefront hosted on Cloudflare Pages. Part of the StakeReloadXS project. Proprietary; see `LICENSE`.

## Commands

Static site with no build step. See `README.md` for how it is served and deployed.

## Rules

- Keep changes small and on a feature branch.
- Don't commit secrets or credentials.
- Record user-visible changes in `CHANGELOG.md` under `[Unreleased]`.
